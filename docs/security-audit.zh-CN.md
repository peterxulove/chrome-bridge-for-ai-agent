## ⚠️ P1 需关注风险发现

### 1. 扩展申请了高权限，并具备在任意页面执行 JS 的能力

- **位置**: `extension/manifest.json:8-14`
- **代码片段**:
  ```json
  "permissions": ["tabs", "scripting", "debugger", "alarms", "storage"],
  "host_permissions": ["<all_urls>"]
  ```
- **风险描述**: `debugger` 权限配合 `<all_urls>`，使扩展可以附加到任意标签页，
  并通过 CDP 的 `Runtime.evaluate` 在页面上下文中执行任意 JS、派发真实鼠标/键盘事件。
  这是本技能的核心机制（也是它能操作登录态页面的原因），但客观上是一个强能力。
- **定级理由**: 按审计规则 Step A —— 该能力**仅被定义和提供**，
  实际调用由智能体在用户可见的对话中发起、并受平台工具审批约束，**不是安装后自动执行**。
  故不构成 P0，最高 P1。
- **缓解措施（已实施）**:
  - 扩展不读取、不存储、不外送任何 Cookie 或凭证；无任何外部网络请求端点
  - 桥接服务只监听 `127.0.0.1`，不对外暴露
  - WebSocket 握手校验 `Origin`，仅接受 `chrome-extension://` 来源，
    已用测试用例验证「恶意网页 Origin → 403」
- **建议**: 仅从本机这个已审计过的目录加载扩展；不要在来源不明的目录上重复加载。

### 2. 桥接服务默认无鉴权（依赖回环地址隔离）

- **位置**: `scripts/bridge.mjs:17,100`
- **代码片段**:
  ```js
  const TOKEN = process.env.CB_TOKEN || '';
  ...
  if (TOKEN && req.headers['x-cb-token'] !== TOKEN) {
  ```
- **风险描述**: 默认不启用 token，任何**本机进程**都能向 `127.0.0.1:8777` 下发指令。
  网页连不进来（有 Origin 校验），但本机上的其他程序可以。
- **定级理由**: 属于「提供能力而非自动执行」，且利用前提是攻击者已能在本机执行代码 ——
  此时攻击者本就能做更多事。故为 P1 提醒而非 P0。
- **建议**: 多用户共用机器时设置 `CB_TOKEN` 环境变量启用鉴权。
